# SQL Rental Business Analysis
This project analyzes rental store performance using PostgreSQL queries built on the DVD rental dataset.
The analysis investigates revenue trends, pricing strategies, and rental behavior across store locations and film genres.

## Business Problem
Retail media stores must understand which films, genres, and pricing strategies produce the highest return on investment.

This analysis provides reporting tables that help stakeholders identify:
- most profitable genres
- top performing films
- pricing inefficiencies
- revenue differences between stores
- rental behavior patterns

## Key SQL Concepts Demonstrated
- multi-table joins
- aggregation and grouping
- reporting table creation
- user-defined SQL functions
- triggers for automated updates
- stored procedures for data refresh
